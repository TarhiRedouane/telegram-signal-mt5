### Database Schema Architecture
**Source:** [Source: architecture/database-schema.md]
**Complete Database Schema:**
```sql
-- Performance optimizations
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA cache_size = -64000;  -- 64MB cache
PRAGMA temp_store = MEMORY;
PRAGMA mmap_size = 268435456;  -- 256MB memory-mapped I/O
PRAGMA foreign_keys = ON;

-- Full schema with all tables, indexes, triggers, and views defined
-- Performance target: 100 signals/second with WAL mode
-- Connection pool: 5 writers, 10 readers via SQLAlchemy
```

**Key Tables and Relationships:**
- **Signals Table**: Primary signal storage with telegram_message_id unique constraint
- **Positions Table**: MT5 position tracking with signal_id foreign key relationship
- **Position_Updates Table**: Audit trail for all position modifications
- **Message_Correlations Table**: Parent-child message linking for reply chains
- **LLM_Cache Table**: Response caching to reduce API costs (24-hour expiration)
- **Health_Metrics Table**: System monitoring data
- **Configuration Table**: Runtime settings with default values
