### Rate Limiting Strategy
**Source:** [Source: architecture/telegram-rate-limiting-strategy.md]
**Human Behavior Simulation:**
- Message reading delays with Gaussian distribution (μ=2000ms, σ=500ms)
- Time-of-day variation: 0.5-1.5 factor based on hour (active 8:00-23:00, night 23:00-8:00)
- Anti-detection measures: max 1000 messages/day per session
- Flood error handling: pause for error.seconds * 1.5 on flood_wait

**Rate Limiter Implementation Pattern:**
```python
async def human_like_delay():
    base_delay = random.gauss(2000, 500)
    time_factor = get_time_of_day_factor()  # 0.5-1.5 based on hour
    final_delay = max(1000, min(5000, base_delay * time_factor))
    await asyncio.sleep(final_delay / 1000)

def get_time_of_day_factor():
    hour = datetime.now().hour
    if 8 <= hour < 23:  # Active hours
        return 1.0
    else:  # Night hours
        return 1.5
```
