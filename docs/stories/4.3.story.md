## Story
**As a** trader,  
**I want** "CLÔTUREZ" and partial close messages to execute immediately,  
**so that** profits are secured when signaled.

## Acceptance Criteria
1. Recognizes close signals: "CLÔTUREZ", "CLOSE", "FERMEZ", "TP HIT", "STOP"
2. Detects partial close patterns: "CLOSE 50%", "FERMEZ MOITIÉ", "PARTIAL TP"
3. Uses correlation engine to identify target position(s)
4. Executes MT5 close order for full or calculated partial volume
5. Updates positions table with close_time, close_price, final profit
6. Handles "CLOSE ALL GOLD" for multiple position closures
7. Confirms closure success and logs any failures with retry mechanism

### MT5 Integration Specifications
**Close Operation Requirements:**
- **OrderSend Function**: Use MT5 OrderSend with OP_CLOSE operation type
- **Volume Calculation**: Partial closes must respect broker lot size minimums (0.01 for GOLD)
- **Price Handling**: Close at current market price (use 0 for immediate execution)
- **Error Handling**: Handle MT5 error codes:
  - **10009** `TRADE_RETCODE_DONE`: Request completed successfully
  - **10014** `TRADE_RETCODE_INVALID_VOLUME`: Invalid volume in request (below minimum or above maximum)
  - **10015** `TRADE_RETCODE_INVALID_PRICE`: Invalid price in request
  - **10006** `TRADE_RETCODE_REJECT`: Request rejected by server
  - **10004** `TRADE_RETCODE_REQUOTE`: Requote received, retry with new price
  - **10012** `TRADE_RETCODE_TIMEOUT`: Request cancelled by timeout
- **Retry Logic**: Implement exponential backoff for retries (3 attempts max)

**GOLD Trading Specifications:**
- **Lot Size**: Minimum 0.01 lots, increments of 0.01
- **Volume Precision**: 2 decimal places for volume calculations
- **Close Price Recording**: Use actual MT5 execution price from result, not requested price
